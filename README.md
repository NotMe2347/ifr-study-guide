# IFR Study Guide (offline PWA)

Static, single-page offline study app: notes, flashcards, quizzes, Logbook Auditor, Checkride Coach.
Serve this folder as-is (e.g., GitHub Pages from the repo root, branch `main`, folder `/`).
All paths are relative, so it works at `https://<user>.github.io/<repo>/`.
Open it once online, then add to Home Screen; it works in airplane mode afterward.
Study aid only; your CFII and the FAA regulations are the authority.
